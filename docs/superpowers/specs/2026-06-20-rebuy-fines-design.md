# 复活罚款设计

## 目标

允许在每位玩家的单局记录中手工填写复活罚款总额。有效牌局的罚款全部汇入赛季奖励池，不影响积分；无效牌局的罚款不计入联赛财务。

## 数据格式

`data/games.json` 的参与者对象新增可选字段：

```json
{
  "playerId": "kai",
  "finalChips": -3800,
  "rebuys": 4,
  "rebuyFine": 80
}
```

- `rebuyFine` 表示该玩家本局实际缴纳的复活罚款总额，不是单次罚款单价。
- 未填写时按 0 元处理。
- 罚款金额由记录者手工决定，不根据 `rebuys` 自动计算。

## 财务计算

仅有效牌局执行以下计算：

```text
本局复活罚款 = 所有参与者 rebuyFine 之和
本局资金来源 = 门票收入 + AA 补足 + 复活罚款
本局赛季池贡献 = 固定赛季池 + 聚餐基金剩余 + 复活罚款
```

罚款不用于支付场地费、当晚奖励或聚餐，因此不会减少 AA 补足；它作为独立资金来源直接进入赛季池。人数不足最低要求的无效牌局，其罚款、门票和其他资金均不进入联赛财报。

## 积分与排名

`rebuyFine` 不改变复活次数、复活扣分、筹码排名、当晚积分或赛季排名。现有 `rebuys` 仍是所有竞技规则的唯一复活次数来源。

## 展示

- 最近一局及历史战报增加“复活罚款”列。
- 联赛财报赛季汇总增加“复活罚款”。
- 每局账单的资金来源显示罚款总额，赛季池贡献说明中列出罚款部分。
- 规则区和 README 说明字段格式、默认值和资金去向。

## 验证

- 有效牌局中 80 元和 20 元罚款合计 100 元，资金来源与赛季池同时增加 100 元并保持账目平衡。
- 未填写罚款的玩家按 0 元处理。
- 无效牌局即使填写罚款，联赛财务仍计 0 元。
- 罚款不改变任何玩家积分。
