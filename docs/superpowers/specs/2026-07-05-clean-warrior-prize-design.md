# 无复活战神奖金调整设计

## 目标

取消弱鸡鼓励奖的 20 元奖金，但保留弱鸡危险区及候选排名展示。将“无复活战神”从无奖金趣味称号升级为第四项正式赛季荣誉，奖金 20 元，并沿用其他正式荣誉的卡片样式和不可重复获奖规则。

## 评选规则

正式荣誉按以下顺序评选：

1. 赛季筹码王
2. 单局 MVP
3. 单局逆袭王
4. 无复活战神

每项奖金均使用 `rules.season.honorPrize`，当前为 20 元。同一玩家不可重复获得正式荣誉；已经获奖的玩家从后续荣誉候选中排除。

无复活战神按本赛季累计复活次数从少到多排序。累计复活次数相同时，总积分高者优先；仍相同时按赛季排名靠前者优先。只考虑至少参加过一局有效牌局的玩家。因为采用“累计复活最少”规则，该奖项不会因无人实现全赛季零复活而空缺；只有赛季没有有效牌局时不产生荣誉。

## 奖池计算

弱鸡候选不再获得奖金，也不再从赛季奖励池预留 `weakPrize`。TOP 4 可分配奖池只扣除实际产生的正式荣誉奖金。

当前四项正式荣誉全部产生时，荣誉奖金总额为 80 元，等同于此前三项荣誉 60 元加弱鸡奖 20 元，因此当前第二赛季的 TOP 4 奖励金额保持不变。整数金额继续由前三名按比例四舍五入、第四名承接尾差，保证 TOP 4 与荣誉奖金之和严格等于赛季奖励池。

## 页面展示

- 弱鸡危险区、危险观察名单和出勤条件继续保留。
- 删除弱鸡危险区中的奖金金额。
- 总览卡片“弱鸡奖候选”改为“弱鸡候选”。
- 荣誉墙说明改为“四项奖金荣誉加两项趣味称号”。
- 无复活战神通过正式荣誉数据结构渲染，自动获得与其他奖金荣誉一致的边框、奖金角标和 20 元展示。
- 复活王和奖金收割机继续作为无奖金趣味称号。

## 数据与代码边界

- 从 `data/rules.json` 删除不再使用的 `weakPrize` 字段，保留 `weakPrizeMinimumAttendance`，因为弱鸡危险区仍依赖最低出勤规则。
- `calculateWeakPlayerCandidate()` 继续只负责趣味候选计算。
- `calculateSeasonHonors()` 负责评选四项正式荣誉和两个趣味称号。
- `calculateSeasonRewards()` 不再接收或发放弱鸡奖金，只根据赛季奖池和正式荣誉计算 TOP 4 奖励。
- HTML 与 CSS 不新增专用卡片结构，无复活战神复用现有 `prize-honor` 样式。

## 验证

自动测试覆盖以下行为：

- 四项正式荣誉均为 20 元且获奖玩家互不重复。
- 无复活战神优先选择累计复活最少、且未获其他正式荣誉的玩家。
- 弱鸡候选不再收到赛季奖金。
- 1419 元奖池在扣除四项荣誉后与 TOP 4 奖励严格守恒。
- 荣誉墙为无复活战神显示正式奖金样式。
- 弱鸡危险区不再渲染奖金文字。
