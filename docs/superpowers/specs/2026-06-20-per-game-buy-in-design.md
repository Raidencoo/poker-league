# 单局门票覆盖设计

## 目标

支持无聚餐牌局按每人 100 元收取门票，同时保留有聚餐牌局默认每人 150 元的现有规则。

## 数据格式

`data/games.json` 的牌局对象新增可选字段：

```json
{
  "buyInPerPlayer": 100,
  "dinnerCost": 0
}
```

- 未填写 `buyInPerPlayer` 时，使用 `rules.money.buyInPerPlayer`，当前默认值为 150 元。
- 填写后只覆盖该局门票，不影响其他牌局。
- `dinnerCost` 仍独立记录；无聚餐时明确填写 0，不根据该字段自动推断门票。

## 财务计算

```text
本局参赛缴费 = 本局实际门票单价 × 参赛人数
```

场地费、300 元当晚奖励和 100 元固定赛季池的扣减规则保持不变。扣除后如有剩余，在 `dinnerCost: 0` 时全部作为聚餐基金剩余汇入赛季奖励池。

## 展示

- 联赛财报的单局账单显示实际门票单价、人数和缴费总额。
- 规则区说明默认 150 元，并注明单局可以通过 `buyInPerPlayer` 覆盖。
- README 给出无聚餐牌局示例。

## 验证

- 5 人牌局填写 100 元时，总缴费为 500 元。
- 未填写覆盖字段时，同样 5 人仍按默认 150 元计算，总缴费为 750 元。
- 无聚餐后的剩余资金继续汇入赛季池。
- 单局财报显示“100 元 × 5 人”。
