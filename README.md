# 德州朋友局 · 赛季积分榜

朋友德州扑克赛季积分榜静态站点。项目可直接部署到 GitHub Pages，页面通过 `data/*.json` 读取规则、玩家和牌局数据，并在浏览器中自动计算排名、积分、当晚奖励、赛季奖励池、聚餐基金和弱鸡鼓励奖候选。

本项目使用 HTML、CSS 和原生 JavaScript，不需要后端、数据库或构建工具。

## 功能

- 当前赛季总览
- TOP 4 领奖台
- 弱鸡鼓励奖专区
- 完整积分榜
- 最近一局战报
- 赛事、积分和奖金规则说明
- 数据驱动渲染，所有结果由 `app.js` 自动计算

## 本地预览

页面通过 `fetch()` 读取 `data/*.json`，建议使用本地静态服务器预览：

```bash
cd poker-league
python3 -m http.server 8080
```

然后在浏览器打开：

```text
http://localhost:8080
```

不要直接双击打开 `index.html`，部分浏览器会在 `file://` 环境下拦截 JSON 读取。

## 数据文件

- `data/rules.json`：赛事、资金、筹码和积分规则。
- `data/players.json`：玩家名单和头像。
- `data/games.json`：每一局牌局记录。

页面展示结果不写死在 HTML 中。修改 JSON 后刷新页面，`app.js` 会自动重新计算。

## 添加玩家

打开 `data/players.json`，在数组中追加玩家：

```json
{
  "id": "new-player",
  "name": "新朋友",
  "avatar": "avatars/default.svg"
}
```

字段说明：

- `id`：玩家唯一标识，不要重复。
- `name`：页面展示名称。
- `avatar`：头像路径，默认可使用 `avatars/default.svg`。

## 记录新一局

打开 `data/games.json`，在数组末尾追加牌局对象：

```json
{
  "id": "game-005",
  "season": "2026-S1",
  "date": "2026-06-12",
  "title": "第五局",
  "dinnerCost": 380,
  "participants": [
    { "playerId": "alex", "finalChips": 2600, "rebuys": 0 },
    { "playerId": "ben", "finalChips": 2100, "rebuys": 1 },
    { "playerId": "chen", "finalChips": 1500, "rebuys": 0 },
    { "playerId": "david", "finalChips": 900, "rebuys": 2 },
    { "playerId": "eric", "finalChips": 600, "rebuys": 1 },
    { "playerId": "frank", "finalChips": 400, "rebuys": 0 }
  ]
}
```

字段说明：

- `id`：牌局唯一编号。
- `season`：所属赛季。只有和 `data/rules.json` 中 `season.current` 一致的牌局会计入当前页面。
- `date`：牌局日期，建议使用 `YYYY-MM-DD`。
- `title`：牌局标题。
- `dinnerCost`：本局实际聚餐费用，饮品费不计入。
- `participants`：本局参与者，至少 6 人才是有效牌局。
- `playerId`：玩家 ID，对应 `data/players.json`。
- `finalChips`：玩家本局最终筹码。
- `rebuys`：玩家本局复活次数。
- `leftEarly`：可选。如果中途无故离场，写 `"leftEarly": true`，当晚积分记 0。

## 赛事规则

- 每人每次缴纳 150 元。
- 至少 6 人才是有效牌局。
- 每 4 次有效牌局结算一个赛季。
- 饮品费不计入牌局资金。
- 如果牌局人数不足 6 人，该局不会计入赛季积分和奖励池。

## 资金规则

- 场地费固定 80 元。
- 当晚奖励固定 300 元：第一名 170 元，第二名 80 元，第三名 50 元。
- 每次固定 100 元进入赛季奖励池。
- 扣除场地费、当晚奖励和固定赛季奖励池后，剩余金额作为本次聚餐基金。
- 如果本次聚餐基金不够，超出部分由实际聚餐人员 AA。
- 如果本次聚餐基金有剩余，剩余金额汇入赛季奖励池。

## 筹码规则

- 每人开局 1000 筹码。
- 输光可无限复活。
- 每次复活获得 500 筹码。
- 复活扣分：第 1 次 -2，第 2 次 -3，第 3 次 -4，第 4 次及以后每次 -5。
- 复活过的玩家不能领取当晚第一名奖励。
- 如果真实筹码第一名复活过，第一名奖励顺延给筹码排名最高的未复活玩家。
- 当晚积分仍按真实筹码排名计算，不受奖励顺延影响。

## 积分规则

当晚积分计算公式：

```text
当晚积分 = 排名基础分 + 筹码奖励分 - 复活扣分
```

排名基础分：

| 名次 | 基础分 |
| --- | ---: |
| 第 1 名 | 12 |
| 第 2 名 | 10 |
| 第 3 名 | 8 |
| 第 4 名 | 6 |
| 第 5 名 | 4 |
| 第 6 名 | 3 |
| 第 7 名 | 2 |
| 第 8 名及以后 | 1 |

筹码奖励分：

- 最终筹码超过 1000 的部分，每满 500 筹码加 1 分。
- 单场筹码奖励分最高 8 分。

最低分和离场规则：

- 全程参与最低 1 分。
- 中途无故离场 0 分。

赛季排名同分规则：

- 累计积分相同时，累计复活次数更少者排名靠前。
- 如果累计积分和累计复活次数都相同，出勤次数更多者排名靠前。
- 如果仍然相同，按玩家名称排序。

## 赛季奖励规则

- 赛季奖励池 = 每局固定 100 元累计 + 每局聚餐基金剩余累计。
- 赛季结算时，先拿出 20 元作为弱鸡鼓励奖。
- 赛季前四名按当前积分榜排序确定；同分时同样按累计复活次数更少者靠前。
- 剩余金额按前四名分配：

| 名次 | 分配比例 |
| --- | ---: |
| 冠军 | 50% |
| 亚军 | 25% |
| 季军 | 15% |
| 第四名 | 10% |

弱鸡鼓励奖规则：

- 本赛季参与不少于 3 次。
- 未进入赛季前四。
- 在符合条件的玩家中，累计积分最低者获得。
