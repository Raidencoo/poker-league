# 德州朋友局 · 赛季积分榜

朋友德州扑克赛季积分榜静态站点。项目可直接部署到 GitHub Pages，页面通过 `data/*.json` 读取规则、玩家和牌局数据，并在浏览器中自动计算排名、积分、当晚奖励、赛季奖励池、聚餐基金和弱鸡候选。

本项目使用 HTML、CSS 和原生 JavaScript，不需要后端、数据库或构建工具。

## 功能

- 当前赛季总览
- 当前与历史赛季完整切换，支持 URL 直达
- 联赛财报：赛季资金汇总、资金去向和每局收支账单
- 赛季荣誉墙：四项奖金荣誉和两项趣味称号
- TOP 4 领奖台
- 弱鸡危险区
- 完整积分榜
- 最近一局战报和历史战报切换
- 赛事、积分和奖金规则说明
- 数据驱动渲染，所有结果由 `app.js` 自动计算

## 本地预览

页面通过 `fetch()` 读取 `data/*.json`，建议使用本地静态服务器预览：

```bash
cd poker-league
python3 -m http.server 8080
```

然后在浏览器打开：

```text
http://localhost:8080
```

不要直接双击打开 `index.html`，部分浏览器会在 `file://` 环境下拦截 JSON 读取。

## 数据文件

- `data/rules.json`：赛事、资金、筹码和积分规则。
- `data/players.json`：玩家名单和头像。
- `data/games.json`：每一局牌局记录。

页面展示结果不写死在 HTML 中。修改 JSON 后刷新页面，`app.js` 会自动重新计算。

## 开启新赛季

赛季按 `data/games.json` 中的录入顺序自动划分，每 4 局有效牌局结算一个赛季：

- 第 1-4 局有效牌局：`2026-S1`
- 第 5-8 局有效牌局：`2026-S2`
- 第 9-12 局有效牌局：`2026-S3`

继续在 `data/games.json` 数组末尾追加新牌局即可；当第 5、9、13 局有效牌局出现时，页面会自动进入新赛季。旧赛季数据继续保留在 `data/games.json` 中，可以通过页面顶部的“查看赛季”选择器随时切换；不同赛季的积分、排名、奖池、荣誉、财报和战报会分别计算。

牌局的 `id` 必须保持全局唯一，可以继续使用 `game-009`、`game-010`；`title` 仅用于页面展示，可以写“第9局”或“新赛季第1局”。

`data/rules.json` 中的 `season.current` 只作为空数据或赛季名称前缀的备用值。已有牌局会按录入顺序和 `gamesPerSeason` 自动判断当前赛季，单局里的 `season` 字段也不会参与积分结算分季。

## 查看历史赛季

- 页面会根据 `data/games.json` 中的有效牌局顺序自动生成全部赛季，不需要额外维护赛季列表。
- 当前赛季由最新一局有效牌局所在的 4 局分组自动决定，其他赛季标记为“已结束”。
- 切换赛季后，总览、财报、动态、荣誉、TOP 4、积分榜、玩家档案和历史战报会一起切换。
- URL 会同步保存所选赛季，例如 `?season=2026-S1`，可以刷新或直接分享。
- 历史赛季使用当前 `data/rules.json` 中的规则重新计算，不保存独立规则快照。

## 添加玩家

打开 `data/players.json`，在数组中追加玩家：

```json
{
  "id": "new-player",
  "name": "新朋友",
  "avatar": "avatars/default.svg"
}
```

字段说明：

- `id`：玩家唯一标识，不要重复。
- `name`：页面展示名称。
- `avatar`：头像路径，默认可使用 `avatars/default.svg`；建议使用压缩后的 SVG 头像，避免 GitHub Pages 加载过慢。

## 记录新一局

打开 `data/games.json`，在数组末尾追加牌局对象：

```json
{
  "id": "game-006",
  "date": "2026-06-26",
  "title": "第六局",
  "dinnerCost": 380,
  "venueFee": 120,
  "participants": [
    { "playerId": "alex", "finalChips": 1600, "rebuys": 0 },
    { "playerId": "ben", "finalChips": 1100, "rebuys": 1, "rebuyFine": 20 },
    { "playerId": "chen", "finalChips": 500, "rebuys": 0 },
    { "playerId": "david", "finalChips": -100, "rebuys": 2 },
    { "playerId": "eric", "finalChips": -400, "rebuys": 1 },
    { "playerId": "frank", "finalChips": -600, "rebuys": 0 }
  ]
}
```

字段说明：

- `id`：牌局唯一编号。
- `season`：可选旧字段，仅作为人工备注或历史兼容；页面实际按 `games.json` 数组顺序每 4 局有效牌局自动分季。
- `date`：牌局日期，建议使用 `YYYY-MM-DD`。
- `title`：牌局标题。
- `buyInPerPlayer`：可选。本局每人的实际门票；不填写时使用 `data/rules.json` 中的默认门票 150 元。
- `dinnerCost`：本局实际聚餐费用，饮品费不计入。
- `venueFee`：可选。本局实际场地费；如果不填写，使用 `data/rules.json` 中的默认场地费。
- `participants`：本局参与者，至少 5 人才是有效牌局。
- `playerId`：玩家 ID，对应 `data/players.json`。
- `finalChips`：玩家本局筹码净值，即 `最终筹码 - 1000`。例如最终剩 100，填写 `-900`；最终为 3280，填写 `2280`。
- `rebuys`：玩家本局复活次数。
- `rebuyFine`：可选。该玩家本局实际缴纳的复活罚款总额；不填写时按 0 元处理。
- `leftEarly`：可选。如果中途无故离场，写 `"leftEarly": true`，当晚积分记 0。

无聚餐牌局按每人 100 元收取时，在该局同时填写：

```json
{
  "buyInPerPlayer": 100,
  "dinnerCost": 0
}
```

`buyInPerPlayer` 只覆盖当前这一局。扣除场地费、当晚奖励和固定赛季池后，如果仍有剩余，继续按现有规则汇入赛季奖励池。

## 赛事规则

- 默认每人每次缴纳 150 元；单局可以通过 `buyInPerPlayer` 覆盖，无聚餐时可填写 100 元。
- 至少 5 人才是有效牌局。
- 每 4 次有效牌局结算一个赛季。
- 饮品费不计入牌局资金。
- 如果牌局人数不足 5 人，该局不会计入赛季积分和奖励池。

## 资金规则

- 默认场地费为 80 元，可在单局 `venueFee` 中按实际花销覆盖。
- 本局门票总收入 = 本局 `buyInPerPlayer`（未填写则为 150 元）× 实际参赛人数。
- 当晚奖励固定 300 元：第一名 170 元，第二名 80 元，第三名 50 元。
- 每次固定 100 元进入赛季奖励池。
- 扣除本局场地费、当晚奖励和固定赛季奖励池后，剩余金额作为本次聚餐基金。
- 如果本次聚餐基金不够，超出部分由实际聚餐人员 AA。
- 如果本次聚餐基金有剩余，剩余金额汇入赛季奖励池。
- 有效牌局中的复活罚款作为独立资金来源，全额汇入赛季奖励池；无效牌局的罚款不计入联赛财务。

## 筹码规则

- 每人开局 1000 筹码。
- 输光可无限复活。
- 每次复活获得 500 筹码。
- 复活扣分：第 1 次 -2，第 2 次 -3，第 3 次 -4，第 4 次及以后每次 -5。
- `rebuyFine` 由记录者按玩家手工填写本局罚款总额，不根据复活次数自动计算，也不影响积分。
- 复活过的玩家不能领取当晚第一名奖励。
- 如果筹码净值第一名复活过，第一名奖励和第一名基础分顺延给筹码排名最高的未复活玩家。
- 顺延只影响当晚名次和排名基础分；筹码奖励分仍按各自筹码净值计算。

## 盲注规则

- 每个盲注级别持续 1 小时。
- 第 1 小时：小盲 5 / 大盲 10。
- 第 2 小时：小盲 10 / 大盲 20。
- 第 3 小时及以后：小盲 20 / 大盲 40，盲注不再继续提高。
- 升盲时，当前手继续使用旧盲注，下一手开始使用新盲注。
- 复活仍固定获得 500 筹码。

## 积分规则

当晚积分计算公式：

```text
当晚积分 = 排名基础分 + 筹码奖励分 - 复活扣分
```

排名基础分：

| 名次 | 基础分 |
| --- | ---: |
| 第 1 名 | 12 |
| 第 2 名 | 10 |
| 第 3 名 | 8 |
| 第 4 名 | 6 |
| 第 5 名 | 4 |
| 第 6 名 | 3 |
| 第 7 名 | 2 |
| 第 8 名及以后 | 1 |

筹码奖励分：

- 筹码净值为正时，每满 500 筹码加 1 分。
- 单场筹码奖励分最高 8 分。

最低分和离场规则：

- 全程参与的排名基础分最低 1 分。
- 复活扣分会继续扣除，因此当晚总积分可能为负数。
- 中途无故离场 0 分。

赛季排名同分规则：

- 累计积分相同时，累计复活次数更少者排名靠前。
- 如果累计积分和累计复活次数都相同，出勤次数更多者排名靠前。
- 如果仍然相同，本赛季累计筹码净值更高者排名靠前。

## 赛季奖励规则

- 赛季奖励池 = 每局固定 100 元累计 + 每局聚餐基金剩余累计。
- 四项正式荣誉每项奖励 20 元；同一玩家不可重复领取。
- 实际发出的荣誉奖金从 TOP 4 可分配奖池中扣除；奖项空缺时，对应奖金退回 TOP 4 奖池。
- 赛季前四名按当前积分榜排序确定；同分时沿用“少复活、多出勤、累计筹码净值更高”的完整规则。
- 奖励金额以整数元结算；前三名按比例四舍五入，第四名领取剩余尾款，确保荣誉奖和 TOP 4 奖励总和严格等于赛季奖励池。
- 剩余金额按前四名分配：

| 名次 | 分配比例 |
| --- | ---: |
| 冠军 | 50% |
| 亚军 | 25% |
| 季军 | 15% |
| 第四名 | 10% |

弱鸡危险区规则：

- 本赛季参与不少于 3 次。
- 未进入赛季前四。
- 在符合条件的玩家中，累计积分最低者成为当前候选。
- 弱鸡危险区只作趣味展示，不发放奖金。

### 赛季荣誉奖金

正式荣誉按以下顺序评选。已经获得前一项奖金荣誉的玩家，不再参与后续奖金荣誉评选：

1. **赛季筹码王（20 元）**：本赛季所有有效牌局中，单局筹码净值纪录最高。不是比较四局累计筹码净值。纪录相同时依次比较总积分更高、累计复活更少、出勤更多、赛季排名更高。
2. **单局 MVP（20 元）**：有效牌局中单局积分最高。并列时依次比较该局筹码净值更高、复活更少、当晚名次更高。
3. **单局逆袭王（20 元）**：从第 2 局有效牌局开始，比较玩家该局前后的赛季总榜排名，上升名次最多者获奖。第一局和玩家首次登场均不参与；并列时依次比较该局积分、该局筹码净值、复活更少、赛后排名更高。
4. **无复活战神（20 元）**：在尚未获得其他正式荣誉的玩家中，赛季累计复活次数最少者获奖。并列时依次比较总积分更高、赛季排名更高。

如果没有玩家在第 2 局及之后实现总榜排名上升，则单局逆袭王空缺，对应 20 元留在 TOP 4 奖池。复活王和奖金收割机为无奖金趣味称号。
